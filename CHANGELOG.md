# Changelog

## 1.2.0 — 2026-09-28

### Interface refresh

- Replace the text-only menu with an account-switching popover, account avatars, activity counts, and quick repository actions.
- Introduce a resizable workspace with sidebar navigation for accounts, folder rules, push guard, SSH keys, and preferences.
- Redesign account cards and display the current global Git identity separately from saved account identities.
- Apply a shared design system with adaptive light and dark colors, consistent forms, hover states, and visible keyboard focus.
- Refresh GitHub sign-in with a reusable authorization-code panel and a copy-code action.
- Redesign cloning and repository checking, including a highlighted drop target and repository fixes that stay outside the scrollable report.
- Improve empty, loading, and error states, plus layouts for long account names and large activity counts.

### Version

- App version: `1.2.0`; bundle build: `3`; Git tag: `v1.2.0`.
- Continues to support macOS 13 and later with no additional dependencies.
